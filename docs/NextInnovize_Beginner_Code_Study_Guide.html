1. 🟢 Start Here — What Are We Building?

The project contains an enquiry form. A customer enters name, email, phone, company, service and message. JavaScript sends that data to a Spring Boot backend. The backend stores it in Google Cloud. A separate enquiries page calls the GET API and displays the saved records.

Customer→HTML→JavaScript→Spring Boot API→Google Cloud
Core idea: The browser does not directly save the enquiry to Google Cloud. The backend is responsible for database communication.

6. 🟨 JavaScript — Browser Logic

Find an element

const enquiryForm =
    document.querySelector(".enquiry-form");

document represents the current HTML page. querySelector() searches for an element using a CSS selector. The result is stored in enquiryForm.

Listen for submit

enquiryForm.addEventListener("submit", function(event) {
    // runs when form is submitted
});

addEventListener() tells JavaScript to wait for an event and run a function when it happens.

Stop normal form behavior

event.preventDefault();

Normally a form may reload/navigate. We stop that because JavaScript will send the request using fetch().

Read an input

const name =
    document.querySelector("#name").value;

#name means the element with id="name". .value gets what the user typed.

7. 📤 JavaScript POST — Sending the Form

const enquiryData = {
    name: name,
    email: email,
    phone: phone,
    company: company,
    service: service,
    message: message
};

This creates a JavaScript object containing the six enquiry values.

Convert to JSON

Converts the JavaScript object into JSON text suitable for the HTTP request body.

Send to Spring Boot

const response = await fetch(

    {
        method: "POST",
        headers: {
            "Content-Type": "application/json"
        },

);

10. 🎯 EnquiryController.java — API Entry Point

@RestController
@RequestMapping("/api/enquiry")
public class EnquiryController {

    private final EnquiryService enquiryService;

    public EnquiryController(EnquiryService enquiryService) {
        this.enquiryService = enquiryService;
    }

    @PostMapping
    public Enquiry save(@RequestBody Enquiry enquiry) {
        return enquiryService.saveEnquiry(enquiry);
    }

    @GetMapping
    public List<Enquiry> getAll() {
        return enquiryService.getAllEnquiries();
    }
}
@RestController tells Spring this class contains REST endpoints.
@RequestMapping("/api/enquiry") creates the base URL.
@PostMapping handles POST requests.
@GetMapping handles GET requests.
@RequestBody converts JSON request data into an Enquiry Java object.
return enquiryService.saveEnquiry(enquiry) sends the work to the service.
Controller's job = receive HTTP request → call service → return response.

11. ⚙️ EnquiryService.java — Middle Layer

@Service
public class EnquiryService {

    private final EnquiryRepository enquiryRepository;

    public EnquiryService(EnquiryRepository enquiryRepository) {
        this.enquiryRepository = enquiryRepository;
    }

    public Enquiry saveEnquiry(Enquiry enquiry) {
        return enquiryRepository.save(enquiry);
    }

    public List<Enquiry> getAllEnquiries() {
        return enquiryRepository.findAll();
    }
}
@Service tells Spring this is a service component.
private final EnquiryRepository stores a reference to the database layer.
Constructor injection lets Spring provide the repository object.
saveEnquiry() calls the repository's save().
getAllEnquiries() calls the repository's findAll().
The service is the middle layer. It prevents the controller from directly handling database code.

12. 🗄️ EnquiryRepository.java — Database Layer

Imports

import com.google.cloud.datastore.Datastore;
import com.google.cloud.datastore.DatastoreOptions;
import com.google.cloud.datastore.Entity;
import com.google.cloud.datastore.Key;
import com.google.cloud.datastore.KeyFactory;
import com.google.cloud.datastore.Query;

These classes let Java create keys, entities and queries and communicate with Google Cloud.

Repository class

@Repository
public class EnquiryRepository {
    private final Datastore datastore;
}

@Repository marks the class as a persistence/database component. Datastore is the Google Cloud client used by this class.

Connect to Google Cloud

public EnquiryRepository() {
    this.datastore =
        DatastoreOptions
            .getDefaultInstance()
            .getService();
}

getDefaultInstance() obtains the default configuration. getService() obtains the Datastore client. this.datastore stores that client in the class.

The Google client can use your configured Application Default Credentials (ADC) when running locally.

13. 💾 Repository Save — Line-by-Line

1. Key factory

KeyFactory keyFactory =
    datastore.newKeyFactory()
        .setKind("Enquiry");

newKeyFactory() creates a helper for database keys. setKind("Enquiry") says records belong to the Enquiry kind.

2. Unique key

Key key =
    datastore.allocateId(keyFactory.newKey());

newKey() creates a key without a final ID. allocateId() asks Datastore to generate a unique ID.

3. Entity

Entity entity = Entity.newBuilder(key)
    .set("name", enquiry.getName())
    .set("email", enquiry.getEmail())
    .set("phone", enquiry.getPhone())
    .set("company", enquiry.getCompany())
    .set("service", enquiry.getService())
    .set("message", enquiry.getMessage())
    .build();

An Entity is the database representation. Each .set() creates a property in the stored record.

4. Actual database write

datastore.put(entity);

This is the important line that actually saves the entity to Google Cloud.

5. Return

return enquiry;

The repository returns the Java object to the service, then the service returns it to the controller.

Creating an object is not the same as saving it. datastore.put(entity) performs the database write.

14. 📥 Repository Fetch — Line-by-Line

public List<Enquiry> findAll() {

    List<Enquiry> enquiries = new ArrayList<>();

    Query<Entity> query =
        Query.newEntityQueryBuilder()
            .setKind("Enquiry")
            .build();

    for (Entity entity : datastore.run(query)) {

        Enquiry enquiry = new Enquiry();

        enquiry.setName(entity.getString("name"));
        enquiry.setEmail(entity.getString("email"));
        enquiry.setPhone(entity.getString("phone"));
        enquiry.setCompany(entity.getString("company"));
        enquiry.setService(entity.getString("service"));
        enquiry.setMessage(entity.getString("message"));

        enquiries.add(enquiry);
    }

    return enquiries;
}
new ArrayList creates an empty list to hold results.
Query.newEntityQueryBuilder() starts building a database query.
setKind("Enquiry") asks for Enquiry records.
datastore.run(query) executes the query.
for (Entity entity ...) processes every returned database entity.
entity.getString("name") reads a stored property.
enquiry.setName(...) puts that value into a Java Enquiry object.
enquiries.add(enquiry) adds the object to the result list.
return enquiries returns all fetched records.

18. 🐞 Eclipse Debugging

Put breakpoints in your own project files instead of immediately stepping into framework/library code.

BreakpointWhat you learn
Controller POSTDid the request reach Spring Boot?
Service saveEnquiry()Did Controller call Service?
Repository save()Did Service call Repository?
datastore.put(entity)What entity is about to be stored?
Controller GETDid the GET request reach backend?
Repository findAll()What query/results are returned?
Step Over executes the current line without entering the called method. Step Into enters the called method and can take you into Spring, Java, gRPC or Google libraries. For learning your own project, use breakpoints and Step Over first.
